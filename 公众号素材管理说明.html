公众号素材管理说明

功能概述

自动采集校墙热点内容，生成精美的公众号图文素材（包含天气、一言等丰富内容），上传到草稿箱后手动审核发布。

访问地址

http://localhost:3000/mp-draft

核心功能

1. 一键生成今日精选

  • 自动获取最近24小时的热门帖子
  • 自动生成天气信息
  • 自动获取每日一言
  • 生成精美卡片样式的图文内容
  • 自动上传到公众号草稿箱

2. 手动选择帖子

  • 加载热点帖子列表
  • 点击选择想要发布的帖子（可多选）
  • 预览生成的图文内容
  • 上传到公众号草稿箱

3. 精美卡片样式

生成的图文包含以下精美卡片：

  • 天气卡片：渐变色背景，显示温度、天气状况、风力、湿度等
  • 一言卡片：左侧边框装饰，显示诗词、名言等
  • 帖子卡片：编号圆圈、渐变色顶部边框、阴影效果
  • 尾部卡片：引导访问校园墙

配置说明

必需配置

在 .env 文件中添加：

# 微信公众号Secret（必需）
WECHAT_SECRET=你的公众号Secret

可选配置

# 和风天气API Key（免费，每天1000次请求）
# 注册地址：https://dev.qweather.com/
WEATHER_API_KEY=你的和风天气API Key

# 默认城市
WEATHER_CITY=嘉善

# 默认封面图片media_id（可选）
MP_DEFAULT_THUMB_MEDIA_ID=

获取和风天气API Key

  1. 访问 https://dev.qweather.com/
  2. 注册账号
  3. 创建应用，获取 Key
  4. 免费版支持每天1000次请求，足够使用

使用步骤

方式一：一键生成

  1. 访问 http://localhost:3000/mp-draft
  2. 点击"🚀 一键生成今日精选"按钮
  3. 系统自动完成所有操作
  4. 登录 公众号后台
  5. 进入"草稿箱"查看生成的图文
  6. 编辑美化（可选）
  7. 手动发布

方式二：手动选择

  1. 点击"🔥 加载热点帖子"
  2. 点击选择帖子（可多选）
  3. 点击"📝 生成图文素材"预览
  4. 点击"📤 上传到公众号草稿箱"
  5. 登录公众号后台编辑发布

API接口

获取热点帖子

GET /api/mp/hot-posts?hours=24&limit=10

获取辅助信息（天气、一言）

GET /api/mp/extra-info

生成图文内容

POST /api/mp/generate-content
Body: {
  "postIds": [1, 2, 3],
  "template": "daily-summary",
  "includeWeather": true,
  "includeHitokoto": true
}

创建草稿

POST /api/mp/create-draft
Body: {
  "articles": [...]
}

一键生成今日精选

POST /api/mp/publish-daily
Body: {
  "hours": 24,
  "limit": 10
}

获取草稿列表

GET /api/mp/drafts?offset=0&count=20

删除草稿

DELETE /api/mp/draft/:mediaId

注意事项

  1. 发布频率限制
  2. 订阅号：每天可群发1次

  3. 服务号：每月只能群发4次（需认证）

  4. 图片要求

  5. 封面图：900x383像素（2.35:1）
  6. 文中图片：宽度不超过1080像素

  7. 格式：JPG、PNG、GIF

  8. 内容审核

  9. 上传到草稿箱后，建议在公众号后台再次审核
  10. 检查排版、错别字等

  11. 确认无误后再发布

  12. API限制

  13. 微信API有调用频率限制
  14. 不要频繁点击生成按钮
  15. 建议每天使用1-2次即可

技术实现

  • 天气数据：和风天气API（或默认模拟数据）
  • 一言数据：Hitokoto API（https://v1.hitokoto.cn/）
  • 卡片样式：CSS渐变色、圆角、阴影等现代设计
  • 图文生成：HTML内联样式，兼容微信公众号编辑器

常见问题

Q: 天气显示不准确？

A: 需要配置和风天气API Key，免费版每天1000次请求足够使用。

Q: 一言加载失败？

A: 一言API是免费的公共接口，如果失败会使用默认名言。

Q: 草稿创建失败？

A: 检查WECHAT_SECRET是否正确配置，确认公众号后台权限正常。

Q: 图片不显示？

A: 微信公众号对图片有严格要求，建议在后台重新上传封面图。
